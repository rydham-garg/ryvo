# Ryvo Technologies Website

Static, GitHub-ready portfolio website for Ryvo Technologies.

## Included
- Responsive one-page website
- Light blue / white visual system
- Electric Blue `#2563EB`
- Violet `#7C3AED`
- Cyan `#06B6D4`
- Deep Navy `#0F172A`
- Founder photo in `founder.jpg`
- Services, About, Process, Testimonials and Contact sections
- Contact via `hello@ryvotech.com`
- No phone number or social-media links

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `founder.jpg`, and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save. GitHub will publish the site.

The site is static and requires no build command, Node.js, database, or backend.
